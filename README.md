# Fast Food Calorie Counter: menu data

Published menu data for the Fast Food Calorie Counter app. This repo holds the
data only. The app's source is private.

The app fetches `index.json` on launch, compares it with its cached copy, and
downloads any chain file whose `checked` date has moved. If anything fails it
falls back to its cached copy, and then to the copy bundled at build time, so a
bad network or a bad file here can never leave the app without menus.

## Layout

```
index.json        version, and the checked date for each chain
chains/<id>.json  one file per chain: mc, hj, kfc, sub, gyg
```

The format is described in the app repo's `data/SCHEMA.md`. In short, energy is
stored in kilojoules per serve as Australian nutrition guides publish it, and
every item carries a `confidence` of `official`, `derived` or `estimate`.

## Where the figures come from

Each chain's own Australian nutrition source: their published PDFs where those
exist, and their per product pages where they do not. Items marked `estimate`
have no official figure yet.

These are published nutrition figures, reproduced for reference. Not affiliated
with any restaurant.

## Updating

Generated by `scripts/publish-data.mjs` in the app repo. Do not hand edit.
